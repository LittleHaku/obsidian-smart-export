# Smart Export

Smart Export turns a selected neighborhood of vault notes into portable representations of both note content and relationships.

## Language

**Standalone Mermaid export**:
A Mermaid-only export that represents selected notes as nodes and discovered links as directed edges.

**Embedded Mermaid diagram**:
A Mermaid graph included inside a Markdown template export alongside other selected template content.

**In-export note link**:
A link from an exported representation of a note to that note's rendered section in the same output document. It is distinct from a link to the original vault note.

**Exported note label**:
The visible name assigned to a note within an export. It uses the note title when unique and adds its vault path only when needed to distinguish equal titles.
