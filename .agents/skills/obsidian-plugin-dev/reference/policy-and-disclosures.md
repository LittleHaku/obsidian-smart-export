# Policy and disclosures

Use this checklist whenever behavior touches network access, external services, or monetization.

## Not allowed in community plugins

- Code obfuscation intended to hide behavior.
- Dynamic ads loaded from the internet.
- Client-side telemetry.
- Self-updating plugin mechanisms.

## Allowed only with clear README disclosure

- Account requirement for full access.
- Paywall or paid features.
- Network use and remote services involved.
- Access to files outside the vault.
- Server-side telemetry (must include privacy policy link).
- Closed-source components.

## Data and privacy expectations

- Default to local/offline behavior where possible.
- Keep data collection minimal and explicit.
- Document what is sent, where, and why.

## Copyright and trademark

- Keep a valid `LICENSE` file.
- Respect dependency licenses and required attribution.
- Avoid branding that implies first-party Obsidian ownership.
